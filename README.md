# dashboard-performance-operacional-cx
Dashboard de performance operacional e CX em Excel, com base sintética de 1.200 atendimentos: filtros por período, canal, equipe e motivo, seis indicadores com alertas (volume, TMA, SLA, produtividade, CSAT e FCR), diagnóstico, plano de ação e aba de validação. Dados fictícios e metas ilustrativas.
